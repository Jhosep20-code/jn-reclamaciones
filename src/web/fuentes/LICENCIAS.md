# Fuentes

Alojadas en local (paquetes npm empaquetados por Vite, subconjunto latino, sin CDN ni Google Fonts):

- **Manrope** (`@fontsource-variable/manrope`): títulos, encabezados y cifras de indicadores. Licencia SIL Open Font License 1.1 (OFL-1.1).
- **Inter** (`@fontsource-variable/inter`): formularios, navegación, tablas y texto. Licencia SIL Open Font License 1.1 (OFL-1.1).

El monograma del logotipo (`src/compartido/logoJN.ts`) son trazados obtenidos de **Libre Bodoni Bold Italic** (SIL Open Font License 1.1); la fuente no se distribuye ni se carga: solo se usan los contornos de las letras J y N.

Los PDF usan Helvetica estándar de PDF (sin incrustar fuentes).
